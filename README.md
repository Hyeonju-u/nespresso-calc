# 네소프레소 절약 계산기

네소프레소 커피머신, 사면 정말 이득일까? 내가 마시는 캡슐과 카페 습관으로 직접 계산해 볼 수 있는 웹 페이지입니다.

👉 **[계산기 바로 가기](https://hyeonju-u.github.io/nespresso-calc/)**

## 왜 만들었나

머신을 사면 카페 값이 줄어든다고들 하지만, 캡슐값도 은근히 부담돼서 실제로 얼마나 남는지 감이 오지 않았습니다. 알아보니 이런 점들이 불편했습니다.

- 사람마다 즐겨 마시는 캡슐 브랜드와 맛, 강도가 달라서 "평균 얼마"라는 숫자가 내 상황에 맞지 않습니다.
- 하루에 캡슐 4개를 마신다면, 고강도 1개와 보통 강도 2개 중 어느 쪽이 싼지처럼 세부적인 가격 차이를 알고 싶었습니다.
- 카페에서는 라떼 4,500원, 아메리카노 4,000원처럼 음료마다 가격이 다르고, 매일이 아니라 주에 몇 번만 갑니다. 이걸 그대로 넣어서 비교해 보고 싶었습니다.
- 아직 머신을 안 산 사람은 머신값을 몇 개월이면 회수하는지가 가장 궁금하고, 이미 산 사람은 캡슐값만 궁금합니다.

그래서 이 둘을 한 화면에서 해결하려고 만들었습니다.

## 기능

크롬 탭처럼 위쪽 탭을 눌러 이동합니다. 첫 탭에서 입력한 값은 다른 탭에서도 그대로 쓰입니다.

1. **내 월 캡슐비**: 머신을 샀는지 여부, 오리지널/버츄오, 마시는 캡슐을 맛별로 고르고 하루 몇 잔인지 정하면 한 달 지출이 나옵니다.
2. **카페 vs 캡슐**: 자주 가는 카페와 마시는 음료의 가격, 일주일에 몇 잔인지 입력하면 월 절약액과 머신값 회수 기간, 누적 지출 그래프를 보여줍니다.
3. **강도별 비교**: 진한 캡슐 1개와 보통 캡슐 2개 중 무엇이 싼지, 하루에 쓰는 개수를 바꾸면 한 달 지출이 어떻게 달라지는지 봅니다.

그 밖에 결과를 **링크로 복사**하거나 **이미지로 저장**, 폰의 **공유하기**로 보낼 수 있고, 이 브라우저에 계산을 저장해 둘 수 있습니다.

## 참고

- 캡슐 가격은 10개입 기준이고, 일부는 쇼핑몰에서 확인한 값이지만 나머지는 비슷한 상품 가격으로 가정한 **예상값**입니다. 화면에서 직접 고쳐서 쓸 수 있습니다.
- 폴바셋·모모스·스타벅스·일리는 네스프레소 정품이 아닌 **오리지널 머신용 호환 캡슐**이라 버츄오에서는 쓸 수 없습니다.
- 방문 통계는 쿠키 없이 [GoatCounter](https://www.goatcounter.com/)로 집계하며, 입력한 값은 전송하지 않습니다.

## 앞으로

반자동·전자동 머신, 핸드드립까지 비교 대상을 넓힐 예정입니다.

## 개발

빌드 과정 없이 `index.html` 하나로 동작합니다. 파일을 열거나 정적 서버로 띄우면 됩니다.

```bash
python3 -m http.server 8000
```
